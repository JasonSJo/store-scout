01문제

반경 300m 원은 상권이 아닙니다

커피는 유효 상권이 좁습니다. 반경 300m 안이어도 6차선 도로에 횡단보도가 없거나, 하천·철로·옹벽이 지나가거나, 경사가 10%를 넘으면 그쪽 수요는 0 에 수렴합니다. 원으로 그린 상권은 그 사실을 통째로 놓칩니다.

그래서 M1 은 OSM 보행 네트워크(4km/h)로 등시선 P5·P10 을 긋고, 단절 요소를 barrier 로 미리 제거한 뒤 잔존율 R 을 냅니다. 같은 10분이라도 실제로 걸어 닿는 면적이 얼마나 남는지가 R 입니다.

변별 불가. 강 건너편도, 6차선 반대편도 같은 상권으로 셉니다.

✓ 등시선 · 잔존율

등시선을 확보하지 못하면 원형으로 폴백하지만, 그때는 산출물 전체에 경고가 붙습니다. 명세가 오차의 가장 큰 부분을 흡수한다고 지목한 단계를 건너뛴 상태이기 때문입니다.

02파이프라인

여섯 모듈

M1 이 상권을 긋고, M2 가 그 안의 수요를 세고, M3 이 경쟁과 나누고, M4 가 매출을 추정하고, M5 가 판정합니다. M6 는 선택이 아닙니다 — 실적으로 계수를 교정하지 않으면 앞의 다섯이 스스로를 검증할 방법이 없습니다.

1

상권 획정 M1

R = area(P10) ÷ (π × 667m²)

보행 등시선 P5·P10. barrier(횡단보도 없는 6차선 이상·하천·철로· 옹벽·경사 10% 초과)는 폴리곤 생성 단계에서 제거합니다.

2

수요 변수 M2

D_am_adj = D_am_같은편 + ( D_am_반대편 × 0.3 )

100m 격자 인구를 등시선과 면적 가중 교차해 H·W 를 냅니다. 유동인구는 출근 진행 방향과 도로 좌·우로 나눠 횡단저항을 적용합니다.

3

경쟁 배분 M3

S_i = ( A_i / d_i^λ ) ÷ Σ ( A_j / d_j^λ )  ·  A = 좌석수^0.5 × 브랜드가중

Huff 모델. 거리는 직선이 아니라 보행 네트워크 거리입니다. 수요가 상권에 흩어져 있으므로 격자마다 점유율을 구해 수요로 가중평균합니다.

4

매출 추정 M4

Mode A ( n ≥ 15 ) 로그선형 회귀  /  Mode B ( n < 15 ) 기준점포 앵커링

출력은 점추정이 아니라 예측구간입니다. 하한·중앙·상한을 out-of-fold 잔차의 25/50/75 분위로 만듭니다 — 정규성을 가정하지 않고 실제로 빗나간 만큼만 벌립니다. 중앙값이 심의 기준값입니다.

5

판정 M5

BEP = F ÷ ( 1 − v )  ·  margin = ( R_median − BEP ) ÷ R_median

통과 / 보류 / 부결 3단. 자기잠식은 등시선 중첩률로 잽니다 — overlap × 기존점 매출 × κ.

6

사후 보정 M6

MAPE > 20% 가 3건 연속 → 모델 재적합

개점 후 6·12개월 실매출로 λ·κ·횡단저항을 교정합니다. 계수를 자동으로 바꾸지 않습니다 — 제안서를 내고 사람이 반영합니다. 심의 기준이 아무도 모르게 바뀌는 쪽이 더 위험합니다.

03판정

점수는 보조입니다.
부결 트리거가 방어선입니다

추정 매출은 틀릴 수 있습니다. 그래서 통과 여부를 점수에 걸지 않습니다. 아래 네 항목은 점수·매출과 무관하게 단독으로 부결시킵니다.

⛔근저당 과다 등기부상 선순위 권리로 보증금 회수가 불확실한 물건 부결
⛔임대인 불일치 등기부상 소유자와 계약 상대가 다름 — 전대차 구조·자기거래 정황 부결
⛔소송 계류 명도 분쟁·소송이 걸려 있는 물건 부결
⛔인허가 불가 용도지역·정화조 용량 등으로 휴게음식점 인허가가 나지 않음 부결
△안전마진 margin < 15% 부결 · margin < 30% 또는 하한 시나리오 적자면 보류 15 / 30

예시의 홍대 어울마당로는 margin 41.8% 로 수익성 기준을 통과하지만 명도 분쟁이 걸려 있어 부결입니다. 실사 칸이 비어 있으면 '통과'에도 잠정 표시가 붙습니다 — 실사 전 통과는 통과가 아닙니다.

05한계

심의 자리에서 반드시 고지할 것

이 시스템이 무엇을 모르는지가 무엇을 아는지만큼 중요합니다. 모든 리포트 말미에 미검증 계수 목록이 인쇄됩니다.

!

Mode B 는 순환논리에 가깝습니다

가중치를 임의로 정하고, 그 가중치로 만든 점수로 매출을 추정하고, 그 추정치로 통과를 판단합니다. 검증되는 것은 사후 실적뿐입니다. 대응 — Mode B 구간에서는 결과를 심의 참고자료로만 쓰고, 최종 판단은 부결 트리거에 둡니다.

!

유동인구 해상도

기지국 기반 추정치는 시간대 정밀도가 낮고 도로 좌·우 구분이 안 되는 경우가 많습니다. D_am 과 방향성 보정은 정확도의 핵심 변수입니다. 대응 — 후보지별 07~09시 현장 통행량 실측 카운트를 필수 절차로 편성합니다. 이 절차 없이는 M2 이후 전 단계의 신뢰도가 확보되지 않습니다.

!

계수 전반이 미검증입니다

λ = 2.2  ·  횡단저항 0.3  ·  κ = 0.5  ·  브랜드 티어 가중  ·  축별 배점

전부 실무 판단 초기값이며 실증 근거가 없습니다. 계수 레지스트리가 검증 상태(MEASURED / ESTIMATED)를 함께 들고 있고, M6 루프가 순차 교정합니다.

!

S < 70 임계가 축퇴합니다

S 는 풀 내 min-max 정규화라 모든 지표에서 동시에 1등이어야 100 에 닿습니다. 예시 데이터의 풀 최댓값은 63.0 이고, 그 결과 'S < 70' 이 여섯 후보지 전부에 무조건 걸려 변별력이 없습니다. 코드가 이 상황을 감지해 심의표에 경고를 찍습니다 — 임계값을 포트폴리오 기준으로 재설정할지, 정규화 방식을 바꿀지는 결정이 필요한 사항입니다.

REQUIRED

사후 보정 루프 없이는 운영하지 마십시오

개점 후 6·12개월 실매출을 수집해 예측 오차를 기록하고, λ·κ·횡단저항을 교정하고, 유효 표본 15개에 도달하면 Mode B 에서 Mode A 로 전환합니다. 이 루프가 없으면 Mode B 는 순환논리를 벗어나지 못하고 모든 계수가 미검증으로 남습니다. 계수 변경은 자동 적용되지 않으며, 변경 이력과 적용 시점을 남겨야 과거 심의와 비교가 끊기지 않습니다.
