# 심의 콘솔

파이프라인이 만든 `analysis/output/심의결과.json` 을 읽어 심의 자료로 보여주는
사내 콘솔입니다. 설치·서버·계정이 필요 없습니다.

> **사내 한정 · 대외 배포 금지.** 화면 상단에 통제 문구가 항상 인쇄됩니다.
> 이 콘솔은 GitHub Pages 배포에서 제외되어 있습니다 — 공개 사이트의 같은 경로에는
> 안내 페이지만 올라갑니다. 쓰려면 저장소를 받아 `app/index.html` 을 로컬로 여십시오.

## 탭

| 탭 | 하는 일 |
|---|---|
| **심의 현황** | 통과/보류/부결 집계, 추정 모드와 모델 품질, 판정표, 데이터 경고 |
| **후보지** | M1~M5 전 지표와 근거, 치명 플래그, S 배점, **입력값 수정** |
| **손익 시뮬** | 임대료·매출·원가율을 움직여 **M5 판정을 다시 계산** — 협상 한계선 찾기 |
| **계수 입력** | 알고리즘의 모든 수치를 직접 입력 — M5 계수는 즉시 반영, 나머지는 파이프라인으로 내보내기 |
| **데이터** | 심의결과 불러오기·비우기 |

## 수치를 손으로 넣는 두 곳

알고리즘에 들어가는 수치는 성격이 둘로 나뉘고, 콘솔에서 넣는 자리도 둘입니다.

| 무엇 | 어디서 | 예 |
|---|---|---|
| **계수** — 모든 후보지에 공통으로 적용되는 값 | **계수 입력** 탭 | 판정 임계값, λ, κ, 배점, 원재료율 |
| **후보지 입력값** — 후보지 한 곳의 실사 결과 | **후보지** 탭 하단 | 임대료, 관리비, 좌석수, 치명 플래그 |

둘 다 같은 규칙을 따릅니다. **M5 로 들어가는 값은 즉시 다시 계산**되고,
**M1~M4·M6 로 들어가는 값은 파일로 내보내 파이프라인을 다시 돌려야** 반영됩니다.
원본(파이프라인 산출)은 건드리지 않고 고친 값만 따로 얹으므로, 언제든 되돌릴 수 있습니다.

## 후보지 입력값 수정

**후보지** 탭에서 후보지를 고르면 아래에 그 후보지의 CSV 행이 그대로 편집 가능한 표로 나옵니다.

| 반영 | 항목 | 무슨 일이 일어나는가 |
|---|---|---|
| **즉시 반영** | 월임대료 · 관리비 · 전용면적 · 치명 플래그 4종 | 고정비 F → BEP → margin 이 다시 계산됩니다. 치명 플래그는 하나만 해당해도 점수·매출과 무관하게 **단독 부결**입니다. 전용면적은 지역 실거래가 대조(M5 시세 신호)에 쓰입니다. |
| **재실행 필요** | 위경도 · 잔존율 R · 도로변 · 좌석수 · 층 · 코너 · 전면폭 · 주차 · 정차 · 방향적합 · 계약조건점수 | M1~M4 로 들어갑니다. **후보지 CSV 내보내기** → `python3 review_sites.py --sites sites.csv` |
| **미사용** | 보증금 · 권리금 | 어떤 모듈도 읽지 않는 심의 참고값입니다. 고쳐도 결과가 바뀌지 않습니다. |

치명 플래그는 **3상태**입니다 — `해당` / `해당 없음` / `미확인(빈칸)`.
미확인은 '해당 없음'과 다르며, 통과 판정을 잠정으로 만들고 그 사실이 화면에 남습니다.

> 월임대료는 M5(고정비)와 M4(Mode B 임대료대비객수효율) 양쪽에 들어갑니다.

> 전용면적은 실거래가 표(`output/실거래가.csv`)가 있을 때만 의미가 있습니다. 그 지역
> 매매 중앙 단가로 기대 월임대료를 환산해, 제시 임대료가 `시세대비_보류배수` 를 넘으면
> **보류**(부결이 아닙니다). 표가 없거나 표본이 적으면 대조 자체를 건너뜁니다.
> 콘솔이 즉시 반영하는 것은 **M5 쪽뿐**이고, 배점까지 반영하려면 CSV 를 내보내
> 파이프라인을 다시 돌려야 합니다.

이 표시(즉시 반영 / 재실행 필요 / 미사용)는 `tests/test_site_inputs.py` 가 파이프라인
소스와 직접 대조합니다 — 반영되지 않은 값을 반영된 것처럼 보이게 하는 것이 심의에서
가장 위험하기 때문입니다.

## 계수 입력

알고리즘의 계수를 코드나 YAML 을 고치지 않고 화면에서 직접 넣습니다. 값마다 **어디까지
반영되는지**가 표시됩니다.

| 반영 | 대상 | 무슨 일이 일어나는가 |
|---|---|---|
| **즉시 반영** | M5 임계값(부결/보류 마진·S·중첩), 잠식계수 κ, 운영 계수(변동비·고정비) | 콘솔이 M5 를 다시 계산합니다. 판정이 바뀌면 표에 `파이프라인 보류 → 통과` 처럼 원래 판정과 함께 표시됩니다. |
| **재실행 필요** | M1·M2·M3·M4·M6 계수, 브랜드 티어 가중, Mode B 배점 | 브라우저가 다시 계산할 수 없습니다(등시선·격자인구·회귀표본이 필요). `coefficients.json` 으로 내보내 파이프라인을 다시 돌려야 반영됩니다. |

명세 기본값은 `analysis/config.py` 와 같아야 하며 `tests/test_config_parity.py` 가 값·검증
상태·설명까지 대조합니다. 화면에 뜬 '명세값'과 파이프라인이 쓰는 값이 갈리면 잘못된 기준으로
심의하게 되기 때문입니다.

### 파이프라인에 넣기

```bash
# 콘솔 → '계수 파일 내보내기' → coefficients.json
cd cafe-trade-area/analysis
cp ~/Downloads/coefficients.json .      # 계수.json 이라는 이름도 그대로 받습니다
python3 review_sites.py                 # 입력값이 M1~M6 전체에 적용됩니다
python3 review_sites.py --계수 /다른/경로/coefficients.json
```

파일이 없으면 명세 기본값으로 돕니다. 입력값이 적용된 산출물에는 심의표의
**“콘솔에서 입력한 계수”** 절과 `심의결과.json` 의 `입력계수` 에 *명세값 → 입력값* 이
그대로 남습니다 — 어떤 숫자가 사람이 넣은 값인지가 심의에서 제일 중요하기 때문입니다.

> 계수를 바꾸는 것은 **심의 기준 자체를 바꾸는 행위**입니다. 과거 심의와 비교가 끊기므로
> 바꾼 값과 근거·적용 시점을 남기십시오.

## 콘솔이 계산하지 않는 것

**M1 등시선 · M2 격자 교차 · M3 Huff · M4 회귀는 브라우저에서 재현하지 않습니다.**
OSM 보행 네트워크, 통계청 격자 인구, 기존점 실적 표본이 있어야 하는 계산이고,
브라우저에서 흉내내면 CLI 와 다른 숫자를 내는 것이 유일한 결과이기 때문입니다.

콘솔이 다시 계산하는 것은 **M5 판정 산술**(BEP · margin · 카니발 · 3단 판정)뿐입니다.
순수 산술이라 이식이 안전하고, 협상 자리에서 즉시 다시 재는 값이라 필요합니다.
그 하나는 `analysis/tests/test_m5_parity.py` 가 무작위 400건 + 임계 경계
(margin 0.15/0.30 · S 70 · overlap 0.30)로 두 구현을 글자 단위까지 대조합니다.

## 불러오기

```
# 파일 열기 — file:// 로 열어도 동작
app/index.html → 데이터 탭 → "심의결과.json 열기"

# output/ 에서 직접 — 로컬 서버로 열었을 때
cd cafe-trade-area && python3 -m http.server 8000
#  → http://localhost:8000/app/ → "output/ 에서 불러오기"
```

**예시 결과** 버튼은 파이프라인 산출을 구워 둔 데이터를 넣습니다
(`analysis/tests/test_demo_sync.py` 가 실제 산출과 같은지 확인합니다).
파이프라인을 고쳤다면 다시 구우십시오:

```bash
cd analysis && python3 review_sites.py && node ../app/js/gen_demo.js
```

## 데이터 저장

불러온 심의결과와 손으로 넣은 계수·후보지 입력값은 **이 브라우저의 localStorage 에만** 남습니다.
서버 전송·계정 없음. 심의결과는 사내 자료이므로 공용 PC 에서 열었다면 **비우기**로 지우고,
입력한 계수는 **전체 명세값으로** 로 되돌리십시오.

## 생김새

소개 페이지(`../index.html`)와 같은 측량 도면 시각 언어 — 종이 바탕에 잉크 먹색,
로스트 시에나 단일 시그널, 모든 수치는 모노스페이스 조판.
Hahmlet / IBM Plex Sans KR / IBM Plex Mono 는 Google Fonts 로 불러오며,
차단되거나 오프라인이면 시스템 한글 폰트로 내려갑니다.

## 파일

```
app/
├── index.html      화면 골격(탭 5개)
├── styles.css      측량 도면 팔레트
└── js/
    ├── util.js       파일 입출력·포맷
    ├── config.js     ★ 계수 레지스트리 (analysis/config.py 포팅 — 파리티 대상)
    ├── inputs.js     ★ 후보지 입력값 편집 (필드별 반영 범위 — 파리티 대상)
    ├── m5.js         ★ M5 판정 산술 (analysis/m5_verdict.py 포팅 — 파리티 대상)
    ├── demo.js       예시 심의결과 (gen_demo.js 로 생성)
    ├── gen_demo.js     ↑ 생성기
    ├── store.js      불러온 심의결과 보관
    └── app.js        탭·렌더링·시뮬레이터·계수 입력
```
