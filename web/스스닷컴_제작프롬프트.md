# 스스닷컴 제작·수정 프롬프트

아래 프롬프트는 현재 구현된 사이트를 바탕으로 재구성한 재사용용 명세입니다. 과거 대화의 원문 전체가 아니라, 최종 요구사항과 구현 범위를 정리한 버전입니다. 동일한 화면을 유지하려면 소스 ZIP도 함께 제공하세요.

---

## 복사해서 사용할 프롬프트

프랜차이즈 회사의 출점 담당자가 온라인으로 고객 상담과 상권 검토를 할 수 있는 한국어 웹사이트 **스스닷컴(Store Scout)**을 만들어 주세요. 브랜드 도메인은 `store-scout.com`입니다.

첨부 소스가 있다면 기존 구조와 기능을 유지하면서 요청된 부분만 수정하세요. 임의로 새 프로젝트를 초기화하거나 기존 상담 데이터를 외부 서비스로 전송하지 마세요.

### 1. 브랜드와 디자인

- 메인 색상: Bright Orange `#FF6D2D`
- 서브 색상: 카이엔 `#BB3E18`
- 배경: 따뜻한 아이보리 `#FAF9F6`, 상담 도구는 밝은 뉴트럴 배경과 흰색 카드
- 로고: 오렌지색 둥근 사각형 안에 굵은 흰색 **스스**. 나침반 아이콘은 사용하지 않습니다.
- 로고 옆에 **스스닷컴**, 그 아래 작은 영문 **STORE SCOUT**을 배치합니다.
- 한글 가독성, 충분한 여백, 얇은 테두리, 정돈된 업무용 화면을 우선합니다.
- 데스크톱과 모바일에 대응합니다. 모바일에서는 필드와 선택 카드를 좁은 화면에 맞게 재배치합니다.
- 실제 데이터가 없는 통계, 성과 수치, 고객 로고를 만들어 넣지 않습니다.

### 2. 메인 페이지 `/`

- 상단 메뉴: 서비스 소개 / 상권분석 / 데이터 안내
- 중앙 헤드라인: **가능성을 찾고, 확신으로 출점하세요.**
- 설명: **고객의 창업 조건부터 상권의 가능성까지. 프랜차이즈 출점의 모든 판단을, 스스닷컴에서.**
- 중앙의 가장 중요한 버튼: **상권분석하기**
- 버튼을 누르면 고객 상담 페이지 `/consultation`으로 이동합니다.
- 서비스 흐름을 고객 상담 → 상권 검토 → 출점 조건 비교로 소개합니다.
- 실시간 유동인구 및 부동산 API가 연결되지 않았다면 반드시 **데이터 연동 준비 중**이라고 표시합니다.

### 3. 고객 상담 페이지 `/consultation`

데스크톱에서는 왼쪽 단계 안내, 중앙 입력 폼, 오른쪽 실시간 상담 요약을 배치합니다.

#### 고객 기본 정보

- 고객명
- 고객 전화번호
- 거주지: 우편번호 / 기본 주소 / 상세주소
- 근무지: 우편번호 / 기본 주소 / 상세주소
- 거주지와 근무지에 각각 **주소 검색** 버튼을 둡니다.
- Kakao 우편번호 검색을 연동하여 우편번호와 기본 주소를 자동 입력합니다.
- 검색 실패 시 오류 안내와 직접 입력 방법을 제공합니다.
- 상세주소는 선택 사항으로 처리합니다.

#### 창업 희망 조건

- 창업 희망 지역 1순위, 2순위, 3순위
- 각 순위는 **시·도 → 시·군·구** 연동 선택 방식
- 1순위 필수, 2·3순위 선택
- 상위 지역을 변경하면 해당 하위 지역을 초기화합니다.
- 중복 지역 및 시·도만 선택한 불완전한 입력을 검사합니다.
- 전국 시·도 목록과 해당 시·군·구 목록을 제공합니다. 행정구역 변경에 맞춰 데이터를 갱신할 수 있도록 분리합니다.
- 희망 평수: 양수 입력, 단위는 평, 약 ㎡ 환산값을 함께 표시
- 희망 상권: **오피스 / 주거 / 학교 / 병원 / 메인 / 복합** 중 하나 선택

#### 투자 계획

- 보증금: 만 원 단위, 0 이상
- 권리금: 만 원 단위, 0 이상
- 보증금과 권리금 합계를 즉시 표시
- 투자금 형태: **현금 / 현금+대출 / 현금+대출+리스** 중 하나 선택
- 보증금과 권리금의 합계를 인테리어 등 모든 비용을 포함한 총 창업비로 표현하지 않습니다.

#### 운영 계획

- 운영 형태: **오토 / 점주+알바 / 점주** 중 하나 선택
- 선택 항목의 설명을 짧게 표시합니다.

### 4. 입력과 완료 동작

- 입력값에 따라 오른쪽 상담 요약과 단계 완료 상태를 갱신합니다.
- 필수 항목, 전화번호, 숫자 범위, 지역 중복을 검사합니다.
- **상담 내용 확인**을 누르면 입력된 조건을 요약한 확인 창을 보여 줍니다.
- 확인 창에서 **상담 파일 내려받기**를 누르면 입력 내용이 담긴 JSON 파일을 내려받습니다.
- **계속 수정하기**로 폼으로 돌아갈 수 있어야 합니다.
- 현재 버전은 상담 정보를 서버나 브라우저 저장소에 영구 저장하지 않습니다. 페이지를 벗어나면 입력값이 초기화된다는 점을 명확히 안내합니다.
- 주소 검색은 Kakao 서비스를 이용한다는 것을 안내합니다.
- 접근 가능한 레이블, 키보드 포커스, 라디오 그룹, 오류 안내를 갖춥니다.

### 5. 현재 코드의 기술 구성

- React 19 + TypeScript
- Vinext / Vite, Next.js 호환 App Router 구조
- Tailwind CSS 4
- shadcn / Base UI 입력·버튼·라디오·대화상자
- Lucide 아이콘
- Sites / Cloudflare Worker 게시 구성
- Kakao 우편번호 스크립트: `https://t1.kakaocdn.net/mapjsapi/bundle/postcode/prod/postcode.v2.js`
- API 사용 전 공식 문서와 최신 사용법을 확인합니다: `https://postcode.map.kakao.com/guide`
- 지원 브라우저에서 상담 조건을 읽고 입력할 수 있는 WebMCP 도구가 있습니다. 이름·전화번호·주소는 읽기 도구에서 반환하지 않습니다.

### 6. 실제 연동과 추후 확장

다음 항목은 현재 미구현입니다. 이미 완성된 것처럼 표현하지 마세요.

- 실시간 유동인구 데이터
- 실시간 상가 매물 데이터
- 지도 기반 상권분석과 추천 결과
- 회원가입, 직원 계정과 권한, 고객 상담 기록의 서버 저장
- `store-scout.com` 사용자 도메인 연결

실시간 데이터 구현을 요청받으면 먼저 데이터 제공처, API 권한, 갱신 주기, 지역 범위, 이용 조건을 확인합니다. API 키는 클라이언트 코드나 저장소에 넣지 않습니다. 개인정보 저장 기능을 추가할 때는 인증·접근권한·보관 및 삭제 정책을 함께 설계합니다.

### 7. 완료 기준

- 메인과 상담 페이지가 정상 실행됩니다.
- 중앙 버튼으로 상담 페이지에 진입할 수 있습니다.
- 모든 상담 항목을 입력·선택할 수 있습니다.
- 주소 검색과 직접 입력 대안이 있습니다.
- 입력 오류와 상담 파일 다운로드를 검증합니다.
- 기존 소셜 미리보기 이미지와 메타데이터를 불필요하게 변경하지 않습니다.
- 타입 검사와 배포 빌드를 수행합니다.
- 구현된 기능과 아직 연결되지 않은 기능을 구분하여 설명합니다.
