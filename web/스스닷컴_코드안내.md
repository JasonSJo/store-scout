## 로컬 실행

Node.js 22.13 이상과 pnpm이 설치된 환경에서 ZIP을 풀고, `package.json`이 있는 폴더로 이동한 후 실행하세요.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다.

```bash
# 타입 검사
pnpm exec tsc --noEmit

# 배포 빌드
pnpm build
```

이 프로젝트는 **Sites/Vinext 기반 원본**으로, 일반 Next.js 전용 프로젝트와 배포 방식이 다릅니다. 다른 호스팅 환경으로 옮길 때는 프레임워크와 빌드/배포 설정을 맞춰야 합니다. 원래 생성 환경에서는 pnpm 11.19.0을 사용했습니다.

## 주요 파일

| 파일 | 역할 |

| `app/page.tsx` | 메인 페이지 |

## 재배포 주의

원본 보존을 위해 `.openai/hosting.json`에는 기존 사이트 프로젝트 ID, `app/layout.tsx`에는 기존 게시 주소가 들어 있습니다. 이는 비밀번호가 아니지만, **새 사이트로 배포할 때 기존 사이트를 덮어쓰지 않도록 새 프로젝트 설정과 주소로 변경**해야 합니다. 기존 사이트 수정 시에는 연결 정보를 유지하세요. 인증 자격증명은 포함되어 있지 않습니다.

## 현재 범위와 제한

- 고객 상담 입력, 주소 검색, 3순위 지역 선택, 조건 요약 및 상담 JSON 다운로드가 구현되어 있습니다.
- 입력값은 페이지 상태에만 유지됩니다. 새로고침하거나 이동하면 사라지며, 고객 DB 저장 및 로그인 기능은 없습니다.
- 주소 검색에는 인터넷 연결이 필요합니다.
- 지역 목록은 정적 데이터입니다. 운영 환경에서는 행정구역 개편을 확인하여 갱신하세요.
- 실시간 유동인구·부동산 정보와 사용자 도메인은 아직 연결하지 않았습니다.
- 별도 제작 프롬프트는 현재 버전을 재구성한 명세입니다. 동일한 결과가 필요하면 프롬프트만 쓰기보다 소스 ZIP을 함께 제공하세요.
